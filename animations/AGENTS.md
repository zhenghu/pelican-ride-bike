# 动画更新与质量排名

每次新增、修改或删除动画，都必须按 README 的“质量排名与更新流程”重新横向评审全榜，并更新 data/quality-ranking.json 后生成目录。

- 评价画面表现、动作自然度、细节完成度，优先保证骑行结构和动作完整性；费用、Token、模型声誉不参与质量排名。
- 在浏览器查看实际画面和多个动画帧，复查主体漂移、车轮分离、脚踏衔接、裁切等问题。不能只根据源码、文件大小或技术标签打分。
- 全部作品必须各有唯一连续名次、简短评语和当前 HTML 的 SHA-256；更新评审日期。
- SHA-256 只用于检测作品变化，不能代替视觉评审。不得只刷新哈希来跳过复评。
- 运行 python3 scripts/update-catalog.py 和 python3 scripts/update-catalog.py --check；核验首页、总览页和前后切换按新排名展示。
- 原始创建日期、用量和质量排名各自独立。修改作品不应改写原始创建日期。
